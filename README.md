## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Real-time temperature updates
- 💧 Humidity & weather condition
- 🎨 Modern glassmorphism UI
- ⚡ Fast API response
- 🔄 Caching support (optional upgrade)

## 🛠️ Tech Stack

- 🌐 Django
- 🎨 Bootstrap 5
- ☁️ OpenWeather API
- ⚡ Requests Library
